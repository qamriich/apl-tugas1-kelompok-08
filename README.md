## Aturan kerja singkat
1. Commit wajib menggunakan akun GitHub masing-masing.
2. Selalu lakukan `git pull` sebelum mulai mengerjakan.
3. Pesan commit harus diawali dengan kode bagian, contoh: `[A5] Menyusun draft ADR-001`.
4. Kerjakan bagian milik sendiri. Untuk bagian orang lain, sepakati dulu dan beri pesan commit yang jelas.
5. Pesan commit diawali kode bagian, contoh: `[A2] tambah register 6 stakeholder`.
6. Jalankan `git pull` sebelum mulai bekerja. Jangan `force push`. Jangan gabung commit (squash).
5. Jangan unggah data pribadi orang lain (nama responden, nomor telepon, tangkapan layar berisi identitas).
